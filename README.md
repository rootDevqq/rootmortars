# RootMortars — Arma Reforger Artillery Calculator

**RootMortars** — артиллерийский калькулятор для **Arma Reforger 1.7+**. SPA на React / TypeScript / Vite / TailwindCSS / Zustand. Все расчёты выполняются прямо в браузере, данные сохраняются в `localStorage`.

**Живой сайт:** https://rootdevqq.github.io/rootmortars/

---

## Основные возможности

### Баллистика
- Мгновенный расчёт дистанции, азимута (тысячные/mils), возвышения, времени полёта (TOF)
- Поддержка **миномётов** (M252, 2Б14) — авто-выбор заряда, поправка на разность высот
- Поддержка **гаубиц и РСЗО** — траектории LOW и HIGH (D-30, M119, M777, Type-63, BM-21)
- **M777 155mm** — снаряд M107 HE с пороховыми зарядами 1–5: режим **АВТО** (минимальный достающий заряд) и **ручной** выбор заряда; поправка на высоту цели и на ветер считаются раздельно для LOW и HIGH
- Режим **Adult Mortars** — расширенные таблицы дальности (до 5900 м)
- Отображение **максимальной дальности** выбранного снаряда в шапке

### Поправка на ветер (Arma Reforger 1.7)
- Ввод скорости (м/с) и направления ветра (откуда дует — как в Метеосводке игры)
- Автоматическое разложение на поперечную (CROSS) и продольную (LONG) компоненты
- **Скорректированный азимут** и **скорректированное возвышение** (через эффективную дальность) — в итоге уже финальные цифры, без ручного пересчёта
- Вывод поправки ветра в результате: ΔAz (mil) и ΔД (м)
- Данные ветра сняты с in-game Ballistic Table (v1.7 vanilla): M821/M819/M853A1 для M252, О-832ДУ/Д-832ДУ/С-832С для 2Б14
- Для **M777** ветер берётся из его собственных in-game таблиц и считается **раздельно для LOW и HIGH** (у навеса снос в разы больше из-за длинного TOF) — в результате показываются отдельные азимут/возвышение по каждой траектории
- **Дисперсия** (разброс, метры) по текущему заряду — из таблиц игры

### Координаты и Grid
- Ввод координат X/Y/H напрямую (для модов с GPS) или через **Grid** (4/6/8 знаков)
- Живой пересчёт X/Y → Grid при наборе координат
- **Уточнение позиции внутри 100м квадрата**: кнопка `⊕` рядом с Grid открывает мини-карту 100×100 м — кликни/потяни маркер или введи смещение +X/+Y (0–99) → точность до 1 м
- **Подложка-скриншот**: в уточнение можно загрузить скрин квадрата (вставка **Ctrl+V**, файл или drag&drop), обвести клетку рамкой — она растянется на весь блок — и кликать прямо по объектам на карте (вставка идёт только в активную панель)
- Уточнение появляется автоматически после ввода 6-значного Grid

### Управление целью
- Виртуальный **Numpad** для смещения цели (шаг: 10, 25, 50, 100, 200, 500 м)
- **Корректура** по дальности и азимуту для ввода пристрелочных поправок
- Накрытие квадрата **(Area Fire)** — сетка огня по площади с шагом, **с учётом ветра** и переключателем траектории **LOW/HIGH** для гаубиц; порядок обхода (ряды / змейка / спираль / из центра / рандом)

### База данных
- Сохранение и быстрая загрузка **огневых позиций**
- Сохранение и группировка **точек целей** по зонам, мгновенный расчёт для всего списка
- Полный **импорт/экспорт** (карты + точки + позиции) в JSON

## Структура данных (`public/data/`)

| Файл | Содержимое |
|---|---|
| `weapons.json` | Баллистические таблицы всех орудий (M252, 2Б14, D-30, M119, **M777**, Type-63, BM-21) |
| `wind.json` | Поправки на ветер per 10 м/с для M252 и 2Б14 (vanilla 1.7) |
| `maps.json` | Игровые карты с постоянными зонами |
| `points.json` | Демо-набор точек для первого входа |

> Данные **M777** (M107 HE, заряды 1–5, обе траектории, колонки ветра) сгенерированы из in-game скринов баллистических таблиц скриптом `scripts/add-m777.cjs` — он же служит референсом для правки цифр.

### Расширение `weapons.json`

```json
{
  "id": "M252",
  "systemType": "mortar",
  "milsPerCircle": 6400,
  "usesHeightCorrection": true,
  "ammo": [{
    "id": "M821",
    "modes": {
      "original": {
        "charges": [{
          "level": 0, "minRange": 50, "maxRange": 400,
          "rangeTable": [
            { "range": 50, "elevation": 1540, "tof": 13.3, "dElev": 61 }
          ]
        }]
      }
    }
  }]
}
```

### Расширение `wind.json`

```json
{
  "weapons": {
    "M252": {
      "M821": [
        { "ring": 0, "d": 10, "t": [
          { "r": 50, "wc": 91, "wl": 3 }
        ]}
      ]
    }
  }
}
```

`wc` — поправка азимута (mils) на 10 м/с бокового ветра, `wl` — поправка дальности (м) на 10 м/с встречного ветра. Масштабируются линейно: `поправка = значение × (скорость / 10)`.

## Баллистическая математика

1. **Дистанция (м):** $D = \sqrt{(X_ц - X_о)^2 + (Y_ц - Y_о)^2}$
2. **Азимут:** $Az = \text{atan2}(dX, dY) \times milsPerCircle / 360$ (оси X/Y как в Arma Reforger)
3. **Поправка на ветер:** ветер раскладывается на продольную ($W_{head} = W \cos\theta$) и поперечную ($W_{right} = W \sin\theta$) компоненты; $\theta$ — угол ветра относительно направления выстрела. Эффективная дальность: $D_{eff} = D + wl \times W_{head}/10$. Поправка азимута: $\Delta Az = wc \times W_{right}/10$.
4. **Возвышение:** линейная интерполяция по таблице на $D_{eff}$
5. **Поправка на высоту** ($\Delta H = H_ц - H_о$):
   - миномёты и **навес гаубицы (HIGH)**: $Elev = Elev - dElev \times \Delta H / 100$ — знак проверен в игре
   - **настил гаубицы (LOW)**: прибавляется геометрический угол места $\text{atan2}(\Delta H, D)$ в mils (табличная колонка `dElev` для настила занижена)
6. **Ветер для гаубицы:** считается отдельно для траекторий LOW и HIGH по их колонкам CROSS/LONG — азимут и дальность корректируются независимо для каждой
