# 🎯 RootMortars — Arma Reforger Artillery Calculator

**RootMortars** — это современный, быстрый и отзывчивый артиллерийский калькулятор для игры **Arma Reforger**. Приложение разработано как Single Page Application (SPA) на базе React, TypeScript, Vite, TailwindCSS и Zustand. 

Все расчеты баллистики происходят мгновенно прямо в вашем браузере, а ваши личные карты, точки целей и огневые позиции надежно сохраняются в локальном хранилище браузера (`localStorage`).

---

## 🚀 Основные возможности

* 🎯 **Высокоточная баллистика:** мгновенный расчет дистанции, азимута (в тысячных/милах), угла возвышения и времени полета снаряда.
* 💥 **Поддержка гаубиц и РСЗО:** автоматический расчет как настильной (**LOW**), так и навесной (**HIGH**) траекторий для артиллерии.
* ⚖️ **Режим минометов:** поддержка оригинального режима (**Vanilla**) и мода **Adult Mortars** с быстрой поправкой на разность высот огневой и цели.
* 📍 **Интерактивная база координат:**
  * Сохранение огневых позиций орудий (`savedGuns`).
  * Сохранение и группировка точек целей (`points`) по секторам/зонам карты.
  * Мгновенный расчет баллистического решения для всего списка точек одновременно прямо во вкладке интерфейса при вводе координат огневой.
  * Поиск по имени или зоне.
* ⌨️ **Корректировка по сетке (Numpad Offset):** быстрая навигация и смещение координат цели с помощью виртуального нумпада (клавиши 1-9 соответствуют направлениям малого тактического квадрата). Возможность задавать шаг смещения (например, 50, 100 или 200 метров) для мгновенной доводки орудия без ручного ввода цифр.
* 🌫️ **Накрытие квадрата (Area Fire) и Корректировка:**
  * **Корректировка наведения:** блок ручной доводки дальности (+/- метров) и азимута (+/- тысячных) для ввода пристрелочных поправок с мгновенным переносом огня.
  * **Накрытие квадрата:** расчет сетки накрытия по площади на основе заданной ширины, глубины и шага распределения снарядов.
* 📥 **Гибкий Импорт и Экспорт (JSON):**
  * **Полный бэкап:** скачивание и загрузка всей базы данных (карты + точки + позиции) в один клик для переноса на другое устройство.
  * **Пораздельный импорт/экспорт:** делитесь отдельными картами, точками под конкретную операцию или списками позиций. Импортируемые точки автоматически привязываются к текущей открытой карте.

## 🛠️ Быстрый старт (Локально)

### Через Node.js (Разработка)

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
3. Откройте в браузере: `http://localhost:5173`

### Через Docker (nginx)

1. Соберите и запустите контейнер:
   ```bash
   docker compose up -d --build
   ```
2. Откройте в браузере: `http://localhost:8080`
3. Чтобы остановить проект: `docker compose down`

## 📐 Баллистическая Математика

1. **Дистанция (м):** $D = \sqrt{(X_{ц} - X_{о})^2 + (Y_{ц} - Y_{о})^2}$
2. **Азимут (тысячные):** $Az = \text{atan2}(dX, dY) \times \frac{milsPerCircle}{360}$ (оси X и Y инвертированы для соответствия координатам Arma Reforger).
3. **Угол возвышения (Elevation):** рассчитывается с помощью линейной интерполяции по таблице баллистических данных для выбранного заряда.
4. **Поправка на разность высот (dH):** для минометов применяется поправка $\text{Elev} = \text{Elev} + dElev \times \frac{dH}{100}$.

## 🔫 Расширение базы орудий (`weapons.json`)

Вся база баллистических данных вынесена в файл `public/data/weapons.json`. Вы можете добавлять новые орудия или корректировать таблицы стрельбы без изменения исходного кода приложения. 

### Структура `weapons.json`

Каждое орудие в массиве `weaponSystems` описывается следующим JSON-шаблоном:

```json
{
  "id": "d30",
  "name": "D-30 Howitzer 122mm",
  "caliber": 122,
  "systemType": "howitzer", // "mortar" | "howitzer" | "mlrs"
  "usesHeightCorrection": false,
  "milSystem": {
    "name": "Warsaw Pact (6000 Mils)",
    "milsPerCircle": 6000,
    "milsPerDegree": 16.6667
  },
  "projectileTypes": [
    {
      "id": "of462_charge_full",
      "name": "ОФ-462 (Полный заряд)",
      "type": "HE",
      "variant": "low_angle", // "low_angle" или "high_angle"
      "minRange": 1000,
      "maxRange": 15400,
      "ballisticTable": [
        { "range": 1000, "elevation": 60, "tof": 4.2 },
        { "range": 2000, "elevation": 124, "tof": 8.6 },
        { "range": 3000, "elevation": 190, "tof": 13.1 }
      ]
    }
  ]
}
```

#### Параметры описания орудия:
* `systemType` определяет логику расчета:
  * `"mortar"` — поддерживает переключение Vanilla/Adult Mortars и коррекцию высоты через `dElev`.
  * `"howitzer"` / `"mlrs"` — вычисляет LOW и HIGH траектории на основе баллистических таблиц.
* `milsPerCircle` — количество тысячных на полный круг (обычно `6000` для советских систем и `6400` для систем NATO).
* `ballisticTable` — массив записей соответствия дальности (`range` в метрах) углу возвышения (`elevation` в тысячных/градусах) и времени полета (`tof` в секундах).

## 📂 Структура файлов данных (`public/data/`)

* `weapons.json` — содержит ТТХ и баллистические таблицы всех орудий (M252, 2Б14 «Поднос», Д-30, M119, Type-63, БМ-21 «Град»).
* `maps.json` — список игровых карт с их фиксированными зонами.
* `points.json` — стартовый демонстрационный набор точек для быстрого ознакомления с калькулятором при первом входе.
